資料來源

  • Claude 額度→Claude 桌面 App 的用量（claude.ai 用量頁）→有對話讀到用量時由 hook 送上來，沒人讀就停在最後一次
  • Codex 額度與 token→電腦上 Codex 的對話紀錄（~/.codex/sessions），對照 Codex 用量頁→收集程式每 10 分鐘送一次
  • Codex 提早重置→官方偶爾會提早重置 Codex 額度，沒有規律（參考站：A codexresetwatch.com、B codex-resets.com、C codex-reset.com）→外部網站，不是這頁收集的
  • Claude 重置與故障→claude-resets.com、官方狀態頁 status.claude.com→外部網站，不是這頁收集的
  • Antigravity 重置→沒有追蹤站，只有 Google 論壇討論（僅供參考）→使用者回報，不是官方
  • 各模型 token 用量→收集程式從頭掃 Claude、Codex 的對話紀錄（同一則回應只算一次）＋ LM Studio 的紀錄→每 10 分鐘只讀新增的部分
  • Antigravity 額度→本機 Antigravity 的額度查詢→收集程式每 10 分鐘送一次
  • 本地模型 token 與電費→LM Studio 的紀錄（Max、Mini 兩台）→收集程式每 10 分鐘送一次
  • PC、DESK 耗電→兩台的電源實測耗電（不是估算）→排程每分鐘送一次
  • 近 15 分鐘 token→收集程式掃 Claude、Codex 的對話紀錄（含快取讀取）→每 10 分鐘一次
  • 這一頁的全部數字→資料 API /board/api/usage→頁面每分鐘自動重抓
